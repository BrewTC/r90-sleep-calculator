# R90 睡眠週期計算器

依照預定起床時間，回推 4、5、6 個 90 分鐘睡眠週期的建議上床時間。網站包含繁體中文 R90 睡眠原則整理、響應式版面與離線使用支援。

## 本機預覽

在專案目錄啟動任一靜態伺服器，例如：

```powershell
python -m http.server 8000
```

開啟 `http://localhost:8000`。

## GitHub Pages

推送至 `main` 後，GitHub Actions 會自動部署網站。首次使用時，請在 repository 的 **Settings → Pages → Build and deployment** 將 Source 設為 **GitHub Actions**。

## 免責聲明

本工具僅供生活規劃與一般資訊參考，不能取代專業醫療建議。90 分鐘為概略平均值，實際睡眠週期會因人而異。
